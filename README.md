# Traininpink Growth Audit

**Live → https://eddieatadapty.github.io/traininpink-flow-rebuild/**

Five ideas to turn more Traininpink users into subscribers, each built into a clickable version of Traininpink's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask her goal, then give it back | +10–20% CR to purchase |
| 02 | Show proof that matches her goal | +5–15% CR to purchase |
| 03 | Explain the 7-day trial before the price | +8–15% CR to purchase |
| 04 | Make the annual saving impossible to miss | +10–15% ARPU |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from Traininpink's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Traininpink. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
